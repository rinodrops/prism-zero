# Docs assets

Images referenced by Marketplace listings (especially Nova Extension Library READMEs) via absolute URLs, for example:

`https://emotiongraphics.jp/tmp/prism-zero/docs/light-nova.webp`

After this repository is on GitHub, prefer:

`https://raw.githubusercontent.com/rinodrops/prism-zero/main/docs/light-nova.webp`

(or the matching path under `screenshots/`).

Keep WebP copies here in sync with `screenshots/*.webp`. Do not put these inside the `.novaextension` bundle — the Library does not render bundled README images.
